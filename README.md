# SRBMiner Updater — releases

Release builds of SRBMiner Updater, a Windows tray app that keeps SRBMiner-Multi up to date.

Download the latest zip from [Releases](https://github.com/weraxzc/srbminer-updater-releases/releases/latest), extract it and run `SrbMinerUpdater.exe`. From 0.4.0 on, the app updates itself from this repo (**Update & relaunch**).
